# Hydraulic Lift

## 📌 Project Overview

This project involves the design and fabrication of a portable hydraulic lift as a 2nd-year academic project.

The hydraulic lift demonstrates the practical application of Pascal's principle, where pressure applied to a hydraulic fluid is used to lift a load.

## 🎯 Objectives

- Design and fabricate a portable hydraulic lifting system.
- Understand the working principle of hydraulic systems.
- Demonstrate the application of Pascal's principle.
- Operate the lift using a hand-operated hydraulic pump.
- Gain practical experience in mechanical design and fabrication.

## ⚙️ Working Principle

The hydraulic lift works based on Pascal's principle.

When force is applied to the hydraulic pump, pressure is transmitted through the hydraulic fluid to the cylinder. The cylinder then produces an upward force that lifts the load.

## 🛠️ Components Used

- Hydraulic cylinder
- Hydraulic hand pump
- Hydraulic fluid
- Metal frame
- Hydraulic hoses
- Supporting structure

## 🔧 Project Highlights

- Portable hydraulic lift
- Hand-operated hydraulic system
- No electric power required for operation
- Designed and fabricated as a hands-on academic project
